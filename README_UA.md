# Бот «Зборівська громада | Світло»

Готовий каркас Telegram-бота для відключень електроенергії.

## Що вже вміє
- 53 населені пункти Зборівської громади;
- кнопки з вибором населеного пункту;
- пагінація списку;
- підписка/відписка на сповіщення;
- збереження підписок у SQLite;
- адміністратор може публікувати повідомлення у канал і надсилати його підписникам;
- `/myid`, `/stats`, `/post`, `/help`.

## Безпека
Не вставляйте токен у цей файл і не надсилайте його нікому. Використовуйте змінну `BOT_TOKEN`.
Старий токен, який був показаний у чаті BotFather, треба вважати скомпрометованим і не використовувати.

## Встановлення
Потрібен Python 3.10+.

1. Встановіть залежності:
   `pip install -r requirements.txt`
2. Створіть змінні середовища за прикладом `.env.example`.
3. Запустіть:
   `python bot.py`

Для Linux:
`export BOT_TOKEN="НОВИЙ_ТОКЕН"`
`export CHANNEL_ID="@Zboriv_Svitlo"`
`export ADMIN_IDS="ВАШ_ID"`
`python bot.py`

## Як отримати свій ID
Запустіть бота і надішліть йому:
`/myid`

Отримане число внесіть у `ADMIN_IDS`.

## Як публікувати відключення
Адміністратор пише боту в особисті:
`/post Кальне`
на наступному рядку:
`⚠️ Відключення електроенергії з 14:00 до 18:00.`

Приклад:
`/post Кальне
⚠️ Відключення електроенергії з 14:00 до 18:00.`

Бот опублікує інформацію в канал і надішле її користувачам, які підписані на «Кальне».

## Важливо
Бот має бути адміністратором каналу з правом публікувати повідомлення.
